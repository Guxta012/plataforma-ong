# 🐾 Ajuda para Aumigos

Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Web.  
O objetivo é criar uma **plataforma fictícia de ONG**, voltada ao **resgate e adoção de cães**, aplicando os fundamentos de HTML5, CSS3 e JavaScript.

---

## 🎯 Objetivo

Desenvolver uma aplicação web completa e acessível para organizações sem fins lucrativos, aplicando boas práticas de:
- Estrutura semântica (HTML5)
- Estilização moderna e responsiva (CSS3)
- Interatividade e validação (JavaScript)
- Versionamento e deploy (Git/GitHub)

---

## 🖥️ Tecnologias Utilizadas

- **HTML5**
- **CSS3 (Flexbox + Grid)**
- **JavaScript (DOM, eventos, validação)**
- **Git e GitHub (controle de versão e deploy)**
